## 배포 상태

기존 운영 주소는 https://fitmind-ai-eight.vercel.app 이며 Vercel 정적 배포다. 현재 CLI와 브라우저에 Vercel 로그인이 없어 기기 인증을 요청한 상태다. 이 문서 작성 시점에는 새 버전을 운영에 배포하지 않았다.

인증 후 기존 프로젝트 fitmind-ai / 팀 metachainart-3942s-projects에 연결하고 production 배포한다. Git 커밋·푸시는 실행하지 않았다.

OAuth AI는 PC의 설치된 인증과 프록시를 사용하는 로컬 기능이다. Vercel 정적 배포에 인증 파일을 올리거나 로컬 AI 서버를 공개하지 않는다. npm start로 실행한 로컬 화면에는 새 추론 선택 기능이 동작한다.
